# STEP1NE MATCH 行銷專欄：寫作規範（給撰稿 agent）

## 檔案格式
- 每篇一個檔：`lib/articles-content/<slug>.ts`，格式照 `lib/articles-content/koc-kol-evaluation-metrics.ts`：
  `import type {Article} from "@/lib/article-types";` → `const article:Article = {...};` → `export default article;`
- 型別定義在 `lib/article-types.ts`。區塊只有三種：`p`（段落）、`list`（條列）、`table`（表格）。
- 站內外連結寫在文字裡，用 `[文字](/path)` 或 `[文字](https://...)`，段落、條列、表格格子都支援。
- **不要改** `lib/articles.ts`、頁面程式或 CSS。寫完跑 `npx tsc --noEmit` 確認沒有錯誤。
- `published`、`updated` 都填 `2026-09-17`；`author` 填 `STEP1NE MATCH 編輯部`。
- `category` 只能用：`品牌指南`、`創作者指南`、`入門觀念`。

## 內容紀律（違反就是錯）
1. **不准編造**：數字、法條、稅率、罰則、平台功能、行情價格，必須來自研究檔或你這次用 WebFetch 讀過原文的一手來源，並放進 `sources`。只有搜尋摘要、沒讀到原文的，不准寫成事實。
2. **法規、稅務只引官方原文**：公平會、財政部／國稅局、衛福部健保署、食藥署、全國法規資料庫。官方沒寫清楚的，照實寫「官方沒有單獨說明」，並建議讀者向國稅局或專業人士確認。
3. **價格行情**：不自己估價格表。引用別人的行情必須標出處、年份，並說明該資料的限制（例如沒寫樣本數）。
4. **不替 STEP1NE MATCH 誇大**：只能提網站上已有的服務描述——品牌提交需求、AI 媒合與配對、顧問人工審核、品牌挑選、策略與執行分析（AI，交付報告）、邀約與條件確認、內容與發布管理（系統化管理）、成效回收、下一波建議（AI 分析＋顧問評估）；嚴選創作者網絡（創作者申請需顧問審核）。不准寫保證效果、客戶數、案例、價格。提到自家服務每篇最多一段，放在最後一節，語氣是「如果你需要」，不硬推。
5. **比較競品**：可以描述公開可查的做法，不貶低、不寫未經證實的缺點。

## 寫法（AEO／GEO）
- 語言：台灣繁體中文、台灣用語，白話，讀者是非專業行銷人或一般創作者。句子短。
- `summary`：3 條，第一條直接回答標題的問題（40–80 字），可被 AI 單獨引用。
- `sections`：5–7 節，`heading` 盡量用讀者會搜尋的問句。每節第一句先講結論。
- 至少一個 `table` 或 `list`，讓比較或步驟一眼看懂。
- `faq`：4–5 題，用研究檔裡實際觀察到的問法；答案 2–4 句、自成一段、不依賴上下文。
- 內鏈：至少 2 個站內文章連結 + 1 個相關站內頁（品牌文連 `/brand-brief` 或 `/#workflow`；創作者文連 `/creators`）。
- 字數：全文約 2,500–4,000 字，寧可精準不要灌水。
- `description`：120 字內，包含主要目標查詢。
- `title`：包含主要目標查詢，40 字內。

## 人味：避免 AI 感（2026-09-17 使用者要求，必須遵守）
- **禁用詞與句型**（出現就改寫）：「在這個……的時代」「隨著……的發展」「讓我們一起」「不僅……更……」「總而言之」「綜上所述」「值得注意的是」「不可或缺」「至關重要」「關鍵在於」「賦能」「打造」「助力」「深入探討」「全方位」「無縫」「一站式」「解鎖」「首先……其次……最後」機械排比、每段結尾都來一句總結或金句、每節都用「以下是……」開頭。
- **不要三點式排比濫用**：不是每件事都要湊成三點。
- **講具體情境**：用品牌行銷人員、創作者實際會遇到的場景舉例（例如「收到一封只寫『想跟你合作，請加 LINE』的私訊」），不要抽象空話。
- **語氣像懂行的前輩在講話**：可以用「老實說」「很多人會卡在這裡」「這點常被忽略」這類自然口語，但不要裝熟、不要浮誇、不用驚嘆號。
- **句子長短交錯**，有短句，不要每句都是「A，B，C。」同一個節奏。
- **可以有明確立場**：資料支持時直接說「不建議這樣做」，不要每句都「可能」「或許」兩面討好；但沒資料支持的判斷不要硬給。
- **不要重複標題的話當開頭**，也不要在結尾把全文再講一遍。
- 寫完自己從頭念一遍，任何一句「換成別的主題也能用」的套話都刪掉。
